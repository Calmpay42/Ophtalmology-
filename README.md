# OphtaSuite (web)

Application de gestion de cabinet d'ophtalmologie. Page unique `index.html`, hébergée en site statique sur Render.

Les données des patients ne sont PAS dans ce dépôt : elles sont sur le serveur Supabase (fonction `ophta-sync`).
À la première ouverture sur un appareil : Paramètres > Sauvegarde > « Entrer un code » et coller le code de connexion.
Ne jamais mettre le code de connexion ni une sauvegarde `.json` dans ce dépôt.
